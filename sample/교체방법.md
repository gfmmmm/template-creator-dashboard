# 샘플 데이터 교체 방법

수업 중 내 계정 수집이 막혔을 때, 이 폴더의 세트를 `data/` 에 덮어쓰면 화면이 바로 채워집니다.
세트는 세 가지입니다 — `뷰티/` · `지식/` · `일상/` (기본 더미는 `지식/` 과 같습니다).

## Claude에게 이렇게 말하세요

> "샘플 뷰티 데이터로 바꿔줘"

## Claude가 하는 일 (직접 하고 싶을 때)

```bash
cp sample/뷰티/*.json data/
cp sample/뷰티/thumbs/* data/thumbs/
```

JSON 4개와 썸네일을 **같이** 옮겨야 합니다. JSON 안의 썸네일 경로가 `data/thumbs/...` 라서
썸네일을 안 옮기면 카드가 빈칸으로 나옵니다.

되돌릴 때는 `sample/지식/` 을 같은 방식으로 덮어쓰면 처음 상태로 돌아갑니다.

> 여기 담긴 계정·게시물·캡션·수치는 전부 지어낸 것입니다. 실제 인물이나 계정이 아닙니다.
