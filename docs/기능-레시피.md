# 기능 레시피 — 이렇게 시키면 이렇게 됩니다

사용자가 자주 원할 기능 8개를 미리 한 번씩 그려본 기록. Claude Code는 새 요청이 오면 여기서 가장 비슷한 것을 찾아 같은 패턴으로 만든다. 각 레시피는 "어떻게 말하나 · 어느 파일을 고치나 · 데이터가 어디서 오나 · 비용 · 주의" 다섯 줄이다.

분류 기준은 `.claude/CLAUDE.md`의 표와 같다 — ① 있는 데이터를 다르게 보여주기(바로) ② 새 데이터(크레딧) ③ Gemini 분석 ④ 이 구조에선 안 되는 것.

---

## 1. 요일별 업로드 히트맵 ①

- 말: "요일별로 언제 많이 올렸는지 한눈에 보게 해줘"
- 파일: `js/app.js`(내 계정 탭 추이 카드 옆에 새 `.card`), `index.html`(카드 자리)
- 데이터: `posts.json` → `my.posts[].timestamp`의 요일·시간대 집계. 새 수집 없음
- 비용: 0
- 주의: 색은 기존 팔레트 변수만. 라이브러리 없이 `<div>` 격자로

## 2. 해시태그 빈도 ①

- 말: "내가 자주 쓰는 해시태그 top 10 보여줘"
- 파일: `js/app.js`(라이브러리 카드 위 작은 칩 줄)
- 데이터: `posts.json` → `caption`에서 `#\S+` 추출·집계
- 비용: 0
- 주의: 클릭하면 캡션 검색창에 그 태그가 들어가게 — 이미 있는 검색 함수 재사용

## 3. 잘 되는 업로드 시간대 ①

- 말: "몇 시에 올린 게 조회수가 잘 나왔는지"
- 파일: `js/app.js`
- 데이터: `posts.json` → 시간대별 `views` 중앙값. 표본 3건 미만인 칸은 회색
- 비용: 0
- 주의: 평균 말고 중앙값(한 건 터진 게 왜곡한다)

## 4. 주간 리포트 문서 ①

- 말: "이번 주 리포트 써줘"
- 파일: 새 파일 `docs/리포트/YYYY-MM-DD.md` (화면 수정 없음)
- 데이터: `posts.json` 최근 7일 게시물·스냅샷 팔로워 증감, `discoveries.json` 이번 주 발굴 상위 3, `analysis.json` 코칭 요약
- 비용: 0
- 주의: Claude가 직접 쓴다. 숫자는 파일에서 읽은 것만, 추정 금지

## 5. 소스 계정 한 곳 팔로워 비교 ②

- 말: "@어떤계정 팔로워 추이도 같이 보고 싶어"
- 파일: `scripts/snapshot.js`(선택 인자로 추가 핸들 1개), `data/posts.json`의 `snapshots[].others{handle:{followers}}`, `js/app.js` 추이 카드에 점선 하나
- 데이터: SC 프로필 조회
- 비용: 계정당 매일 1크레딧(월 30). 먼저 말하고 허락받는다
- 주의: 최대 2곳까지만 권한다. 더 필요하면 풀버전 기능(경쟁사 벤치마크)

## 6. 발굴 릴스에 "내 채널에서 하려면" 한 줄 ③

- 말: "레퍼런스마다 내 채널 버전 아이디어 한 줄씩 붙여줘"
- 파일: `scripts/analyze.js`의 종합 프롬프트에 항목 하나 추가 → `analysis.차용한줄`, `js/app.js` 발굴 모달에 한 줄
- 데이터: 이미 있는 `analysis` + `settings.brief`
- 비용: Gemini 텍스트 호출(무료 한도 안). 기존 분석 건은 재실행 필요(발굴 1건당 1크레딧 — 영상 URL 재획득)
- 주의: 아이디어 "생성"(여러 개 뽑기)은 이 대시보드 범위 밖 — 릴스 대본 기획 도구가 한다

## 7. 텔레그램으로 월요일 요약 받기 ②

- 말: "월요일마다 텔레그램으로 요약 보내줘"
- 파일: 새 `scripts/notify.js`(fetch로 텔레그램 Bot API), `weekly.yml` 마지막 단계, 시크릿 `TELEGRAM_BOT_TOKEN`·`TELEGRAM_CHAT_ID`
- 데이터: 레시피 4의 요약 앞 10줄
- 비용: 0. 단 텔레그램 봇 만들기(@BotFather)와 시크릿 2개 추가가 필요 — 새 외부 서비스라 먼저 안내
- 주의: 봇 토큰은 `.env`와 시크릿에만

## 8. 웹 화면에서 기둥 바꾸는 드롭다운 ④ — 만들지 않는다

- 말: "화면에서 바로 기둥 바꾸게 해줘"
- 답: "이 대시보드는 서버가 없어서 화면에서 바꾼 게 저장될 곳이 없어요. 브라우저에만 남고 폰에서 열면 사라져요. 대신 'M-012는 흥미유발로 바꿔줘'라고 하시면 제가 파일을 고치고 올려서 모든 기기에 반영돼요."
- 같은 답이 나오는 것: 로그인·비밀번호, 여러 명 동시 편집, 실시간 갱신, 댓글·메모 저장
- 이게 필요해지면: 풀버전(서버·DB·로그인이 붙은 것)으로 올라가는 시점
