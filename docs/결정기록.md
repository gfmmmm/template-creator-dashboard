# 결정 기록

이 대시보드에서 무엇을 왜 그렇게 했는지 한 줄씩. Claude Code가 기능을 추가하거나 구조를 바꿀 때마다 아래에 한 줄 덧붙인다 — 날짜 · 무엇 · 어느 파일 · 비용(크레딧) · 이유.
한 달 뒤 돌아와도 "지난번에 이렇게 해두셨어요"라고 이어갈 수 있게 하는 기록이다.
